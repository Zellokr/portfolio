Un portfolio pensado como un pequeño sistema operativo dentro del navegador: escritorio
estilo Ubuntu, terminal con comandos predefinidos, explorador de archivos y ventanas que
se pueden abrir, cerrar, minimizar y maximizar, con una barra lateral para gestionar las
aplicaciones abiertas. Construido con Vue 3, TypeScript y Vite, con Pinia para el estado
y Tailwind CSS junto a Sass para los estilos.
