Una recreación visual de una consola Gameboy construida con Vue y CSS puro, sin
librerías de estilos externas. El objetivo del proyecto fue explorar hasta dónde
se puede llegar usando únicamente CSS para lograr formas, sombras y detalles
propios del dispositivo original.
